# apifuzz Implementation Plan

> **For agentic workers:** Use `superpowers:subagent-driven-development` to implement task-by-task.

**Goal:** Python SDK + CLI that parses API specs (OpenAPI/HAR/Postman), generates and executes OWASP API Top 10 security tests, outputs SARIF/JSON/HTML reports.

**Architecture:** Parser layer converts specs → Endpoint models. Check engine generates test cases per endpoint. Async executor runs tests via httpx. Reporters format findings as SARIF/JSON/HTML.

**Tech Stack:** Python 3.10+, httpx (async), pydantic v2, pyyaml, jsonref, typer, rich, jinja2, pytest, respx

## Task 4: Async HTTP Executor

**Files:** `src/apifuzz/executor.py`, `tests/test_executor.py`

```python
# executor.py skeleton
import asyncio
import httpx
from dataclasses import dataclass
from apifuzz.models.endpoint import AuthConfig

@dataclass
class TestCase:
    method: str
    url: str
    headers: dict
    params: dict
    body: dict | None
    label: str          # human-readable description of what this tests
    check_id: str       # which check generated this

@dataclass
class TestResult:
    test_case: TestCase
    status_code: int
    response_body: str
    response_headers: dict
    elapsed_ms: float
    error: str | None = None

class Executor:
    def __init__(self, auth: AuthConfig, concurrency: int = 10, rate_limit_rps: float = 10.0):
        self.auth = auth
        self._sem = asyncio.Semaphore(concurrency)
        self._rps = rate_limit_rps

    async def run(self, test_cases: list[TestCase]) -> list[TestResult]:
        async with httpx.AsyncClient(timeout=15.0, follow_redirects=True) as client:
            tasks = [self._run_one(client, tc) for tc in test_cases]
            return await asyncio.gather(*tasks)

    async def _run_one(self, client: httpx.AsyncClient, tc: TestCase) -> TestResult:
        async with self._sem:
            # inject auth headers
            headers = dict(tc.headers)
            if self.auth.type == "bearer":
                headers["Authorization"] = f"Bearer {self.auth.token}"
            elif self.auth.type == "apikey":
                headers[self.auth.header_name] = self.auth.token
            elif self.auth.type == "basic":
                import base64
                creds = base64.b64encode(self.auth.token.encode()).decode()
                headers["Authorization"] = f"Basic {creds}"
            try:
                import time
                start = time.monotonic()
                resp = await client.request(tc.method, tc.url, headers=headers, params=tc.params, json=tc.body)
                elapsed = (time.monotonic() - start) * 1000
                return TestResult(tc, resp.status_code, resp.text[:4096], dict(resp.headers), elapsed)
            except Exception as e:
                return TestResult(tc, 0, "", {}, 0.0, str(e))
```
